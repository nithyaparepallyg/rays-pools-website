# Rays Pools & Chemicals — website

Static one-page site (HTML/CSS/JS, no build step). Hosted on GitHub Pages.

- `index.html` — all content
- `assets/styles.css`, `assets/script.js`
- `assets/img/` — photos taken from the 2021 brochure (low resolution; replace with originals when available, same file names)

The enquiry form needs no server: it opens WhatsApp (+91 98440 66321) or the visitor's email app with the details filled in.
